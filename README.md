# Durak Game

## Описание проекта

Консольная реализация карточной игры «Дурак» на языке C++.

Игрок играет против компьютера.

## Возможности

* Колода из 36 карт.
* Четыре масти.
* Определение козырной масти.
* Раздача по 6 карт.
* Игрок против компьютера.
* Атака и защита.
* Добор карт из колоды.
* Определение победителя.

## Реализованные тесты

1. Проверка размера колоды (36 карт).
2. Проверка козыря.
3. Проверка старшей карты одной масти.
4. Проверка невозможности отбоя другой мастью.
5. Проверка старшинства туза над королём.
