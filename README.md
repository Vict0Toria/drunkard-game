# Durak Game (C++)

## Описание проекта

Консольная реализация упрощённой версии карточной игры «Дурак» на языке C++.

Игрок играет против компьютера. В игре используется колода из 36 карт, присутствуют козыри, атака и защита картами.


### Реализовано

* Колода из 36 карт.
* 4 масти.
* Автоматическое перемешивание колоды.
* Определение козырной масти.
* Раздача по 6 карт каждому игроку.
* Игра против компьютера.
* Атака игрока.
* Защита компьютера.
* Атака компьютера.
* Защита игрока.
* Добор карт до 6 после каждого хода.
* Определение победителя.
* Проверка корректности пользовательского ввода.

### Упрощения

В данной версии реализован упрощённый вариант игры:

* За ход атакуют только одной картой.
* Нет подкидывания дополнительных карт.
* Нет переводного дурака.
* Компьютер использует простую стратегию выбора карты.


## Правила игры

1. Создаётся колода из 36 карт.
2. Колода перемешивается случайным образом.
3. Определяется козырная масть.
4. Каждому игроку раздаётся по 6 карт.
5. Игрок выбирает карту для атаки.
6. Компьютер пытается отбиться.
7. Затем компьютер атакует игрока.
8. Игрок выбирает карту для защиты.
9. После завершения хода происходит добор карт.
10. Игра продолжается до определения победителя.


## Реализованные тесты

### testDeckSize()

Проверяет создание полной колоды из 36 карт.

### testTrumpBeatsRegularCard()

Проверяет, что козырная карта бьёт некозырную.

### testHigherCardSameSuit()

Проверяет, что старшая карта одной масти побеждает младшую.

### testLowerCardSameSuit()

Проверяет, что младшая карта одной масти не может побить старшую.

### testWrongSuitCannotBeat()

Проверяет, что карта другой масти без козыря не может побить атакующую карту.

### testTrumpVsTrump()

Проверяет старшинство козырей.

### testAceBeatsKing()

Проверяет, что туз старше короля.

### testSameCards()

Проверяет, что карта не может побить саму себя.

### testCardCountAfterDeal()

Проверяет корректную раздачу карт:

* игроку выдано 6 карт;
* компьютеру выдано 6 карт;
* в колоде осталось 24 карты.
